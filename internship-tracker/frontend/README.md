Internship Tracker

A full-stack web application that helps students organize and track their internship applications in one centralized dashboard. Instead of managing applications through spreadsheets or scattered notes, this platform provides an intuitive interface to monitor application status, manage deadlines, and stay organized during the internship search process.

Live Demo

🔗 https://internship-tracker-mu.vercel.app

Project Overview

Finding internships often involves applying to multiple companies across different platforms. It becomes difficult to remember:

where you applied

which companies responded

upcoming interview rounds

rejected or pending applications

Internship Tracker solves this problem by providing a centralized dashboard where users can manage and monitor their internship journey efficiently.
