# Internship Tracker

Internship Tracker is a simple full-stack web application designed to help students keep track of the internships they apply to. When applying to multiple companies, it becomes difficult to remember application statuses, interview rounds, or deadlines. This project provides a clean interface where users can store and manage all their internship applications in one place.

The goal of this project was to build a practical tool that solves a real problem many students face during internship season, while also practicing full-stack development concepts such as REST APIs, frontend-backend integration, and database operations.

## Features

### Track Internship Applications
Users can add details about internships they have applied to, including company name, role, and other relevant information.

### Application Status Management
Each application can be tracked through different stages such as:
- Applied
- Interview
- Offer
- Rejected

This helps users quickly understand where they stand in the hiring process.

### Update or Delete Entries
Applications can be edited if details change, or removed if they are no longer relevant.

### Simple Dashboard
All applications are displayed in an organized view, making it easy to scan through different opportunities and their current status.
